TXDownloader 隐私政策

摘要

TXDownloader 用于解析和下载用户主动提交的公开 X/Twitter 媒体链接。应用不提供账号登录、私信读取、内容发布或付费内容绕过能力。下载历史和已下载文件主要保存在你的设备上。Release 版本使用 Firebase Analytics 和 Crashlytics 了解产品健康状况、崩溃和非致命错误。

一、适用范围

本政策适用于 TXDownloader App。TXDownloader 是一个面向用户主动提交的公开 X/Twitter 链接的媒体解析与下载工具。我们不提供账号注册、社交平台登录、内容发布、私信读取或付费内容绕过能力。

二、我们处理哪些信息

我们可能处理你主动输入、粘贴或分享给应用的公开 X/Twitter 链接和分享文本；为展示解析结果而临时处理的公开帖子信息；下载历史记录；应用运行日志与错误信息；以及 Firebase Analytics 与 Crashlytics 收集的崩溃日志、诊断信息、应用交互、设备和应用元数据、产品健康信号。

三、使用目的

这些信息仅用于识别公开链接、解析可下载媒体、保存文件到本机、展示下载历史、支持本地预览和播放、诊断失败原因、改进稳定性和了解核心功能是否正常工作。我们不会把这些信息用于广告画像、个性化推荐、用户跟踪或出售。

四、Firebase Analytics 与 Crashlytics

Release 版本使用 Firebase Analytics 和 Firebase Crashlytics。Analytics 用于统计解析、下载、历史筛选、语言切换、通知权限结果等聚合事件。Crashlytics 用于记录崩溃和经过脱敏的非致命异常。我们不会故意把原始 X/Twitter 链接、媒体 URL、Cookie、授权头、Token、推文正文、用户名、文件名或诊断日志正文作为 Analytics 事件参数或 Crashlytics 自定义键发送。

五、第三方服务与网络请求

解析和下载媒体时，应用会访问你提交链接对应的目标页面、公开媒体资源地址，以及必要时的备用解析接口。相关网站或接口可能根据其自身规则记录访问请求。Firebase 数据处理受 Google Firebase 服务条款和隐私实践约束。

六、本地存储、权限与删除

下载历史主要保存在设备本机。下载的图片、视频或 GIF 会保存到系统下载目录或应用可访问的媒体位置。应用需要网络权限；后台下载时可能使用前台服务和通知权限。你可以在应用内删除历史记录，在系统设置中清除应用数据，或通过系统文件管理器删除已下载文件。

七、未成年人保护

本应用不面向儿童单独提供服务。未成年人应在监护人指导下使用本应用，并确保下载和使用公开媒体内容符合法律法规、平台规则及内容权利人的要求。

八、免责声明与联系我们

你应仅下载你有权保存和使用的公开内容，并遵守 X/Twitter 及相关网站的服务条款、版权规则和当地法律法规。TXDownloader 与 X/Twitter 没有关联，不鼓励也不支持下载、传播侵权、违法、隐私泄露或付费受限内容。如果后续功能改变数据处理方式，本政策会同步更新。
