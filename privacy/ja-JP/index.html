概要

TXDownloader は、ユーザーが自ら送信した公開 X/Twitter リンクからメディアを解析し、ダウンロードするアプリです。アカウントログイン、DM へのアクセス、投稿、有料コンテンツの回避機能は提供しません。ダウンロード履歴と保存されたファイルは主に端末内に保存されます。リリース版では Firebase Analytics と Crashlytics を使用し、製品の健全性、クラッシュ、非致命的なエラーを把握します。

1. 適用範囲

本ポリシーは TXDownloader に適用されます。本アプリは、ユーザーが自ら送信した公開 X/Twitter リンクのメディアを解析し、ダウンロードするツールです。アカウント登録、ソーシャルログイン、投稿、DM へのアクセス、有料コンテンツの回避機能は提供しません。

2. 処理する情報

本アプリは、ユーザーが入力、貼り付け、または共有した公開 X/Twitter リンクと共有テキスト、結果表示に必要な公開投稿情報、ローカルのダウンロード履歴、解析・ダウンロード・再生失敗の診断に使うログとエラー情報、Firebase Analytics と Crashlytics が収集するクラッシュログ、診断情報、アプリ操作、端末/アプリのメタデータ、製品健全性シグナルを処理する場合があります。

3. 利用目的

これらの情報は、公開リンクの識別、ダウンロード可能なメディアの解析、ファイルの端末保存、履歴表示、ローカルプレビュー/再生、失敗原因の診断、安定性改善、主要機能が正常に動作しているかの把握にのみ使用されます。広告プロファイル、個別おすすめ、ユーザー追跡、販売には使用しません。

4. Firebase Analytics と Crashlytics

リリース版では Firebase Analytics と Firebase Crashlytics を使用します。Analytics は解析、ダウンロード、履歴フィルター、言語変更、通知権限結果などの集計イベントに使用します。Crashlytics はクラッシュとサニタイズ済みの非致命的例外の記録に使用します。元の X/Twitter リンク、メディア URL、Cookie、認可ヘッダー、トークン、投稿本文、ユーザー名、ファイル名、診断ログ本文を Analytics のイベントパラメータや Crashlytics のカスタムキーとして意図的に送信しません。

5. 第三者サービスとネットワーク要求

メディアの解析とダウンロード時に、本アプリは送信されたリンクの対象ページ、公開メディアリソース、必要に応じた代替解析サービスにアクセスする場合があります。これらのサイトやサービスは各自のルールに基づきリクエストを記録することがあります。Firebase のデータ処理は Google Firebase の規約とプライバシー慣行に従います。

6. ローカル保存、権限、削除

ダウンロード履歴は主に端末内に保存されます。画像、動画、GIF はシステムのダウンロードフォルダまたはアプリがアクセス可能なメディア保存先に保存されます。ネットワークアクセスが必要であり、バックグラウンドダウンロードにはフォアグラウンドサービス通知を使用する場合があります。アプリ内で履歴を削除し、システム設定でアプリデータを消去し、ファイル管理アプリで保存済みファイルを削除できます。

7. 未成年者

本アプリは子どもを対象としていません。未成年者は保護者の指導のもと、法律、プラットフォーム規則、権利者の条件で許可されたコンテンツのみをダウンロードしてください。

8. 免責事項と連絡

保存および利用する権利を持つ公開コンテンツのみをダウンロードし、X/Twitter および関連サイトの規約、著作権規則、適用法を遵守してください。TXDownloader は X/Twitter と提携しておらず、著作権侵害、違法配布、プライバシー侵害、有料コンテンツの回避を推奨または支援しません。データ処理が変わる機能を追加した場合、本ポリシーを更新します。
